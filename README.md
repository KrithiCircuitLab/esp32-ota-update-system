# ESP32 OTA Update System

Complete Over-The-Air firmware update pipeline for 
ESP32 — built with ESP-IDF, validated with Python.

## Features
- WiFi based OTA firmware updates
- Version validation before applying update
- Automatic rollback on failed update
- Post-update automated testing
- Update success/failure logging

## Tech Stack
- ESP32 / ESP-IDF
- C firmware
- FreeRTOS
- Python validation scripts
- AWS IoT Core

## Background
Built on 3+ years of hands-on OTA firmware upgrade 
experience from production IoT devices at Zimplistic 
(Rotimatic appliance) — now reimplemented with 
modern ESP-IDF toolchain.
